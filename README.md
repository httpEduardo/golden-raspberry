# Golden Raspberry Awards Dashboard

![Angular](https://img.shields.io/badge/Angular-19-DD0031?logo=angular&logoColor=white)

A dashboard for exploring Golden Raspberry Awards data, including years with multiple winners, studio totals, producer intervals, and movie searches by year. This version uses local sample data because its original API is unavailable.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:4200` in a browser. The app is built with Angular and can be connected to a live data source in the future.
